Expected Outputs

•  Explainability heatmaps (XAI) showing critical decision regions
•  Confusion matrix for final accuracy
•  Comparison with other algorithms like CNN, RNN, ResNet etc and show performance metrics (confusion matrix, AOC, ROC, graphs)
•  Bar graphs and ROC curves for all algorithms

Comments
Dataset and Model can be change during the development if its not performing well during the development.

Workflow
•  Image Upload - User uploads histopathology image through web interface 
•  Nucleus Detection - HoVerNet identifies and segments individual cell nuclei 
•  Graph Construction - Cells converted to nodes, spatial relationships to edges 
•  GNN Analysis - Graph neural network analyzes cell density patterns and structural irregularities 
•  Results Display -  size estimation, explainability heatmap, confusion matrix for current model and comparison models, comparison with other algorithms and display HoverNet is more accurate, bar graphs, curves and confusion matrix for comparison
